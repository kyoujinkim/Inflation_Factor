# Inflation_Factor

DART 사업보고서 텍스트를 활용해 기업의 인플레이션 관련 노출을 연구하는 Python 프로젝트입니다. 문서 임베딩·유사도, 시장 데이터와의 결합, 팩터 포트폴리오 백테스트를 포함하며, 거시변수 기반 인플레이션 예측 실험도 별도 스크립트로 구성돼 있습니다.


## 연구 결과

2022년 인플레이션 팩터 보고서는 Doc2Vec으로 측정한 인플레이션 방어도를 바탕으로 스타일 팩터를 선택합니다. 요약 표 2에서 인플레이션 국면의 로테이션 전략은 다음과 같이 보고됐습니다.

| 인플레이션 평가 구간 | 전략 연율화 수익률 | KOSPI 200 TR 연율화 수익률 |
|---|---:|---:|
| 2007년 4분기~2008년 2분기 | 1% | −18% |
| 2010년 4분기~2011년 4분기 | 7% | −1% |
| 2022년 1분기~3분기 | −9% | −35% |
| 기간 가중 평균 | 1% | −15% |

보고서는 평균 **연율화 초과수익률 16%p**를 제시합니다. 본문 표 13의 Rotation 열 평균 16%는 주석상 **BM 대비 초과성과**이므로, 이를 절대수익률로 해석해 BM −15%와 다시 차감하면 안 됩니다. 표 2와 표 13에는 일부 기간 일수 표기가 다르므로 정밀 재현 시 날짜를 원자료와 대조해야 합니다.

성능은 인플레이션 국면에 의존합니다. 비인플레이션·정상 국면에서는 방어도 기반 선택의 유용성이 낮아지고 사이즈 팩터가 더 유리한 사례가 제시돼 있습니다. 공시 텍스트 유사도만으로 경제적 민감도나 모든 국면의 수익성을 확정하지 않습니다.

출처: [221103_인플레이션_팩터.pdf](https://github.com/kyoujinkim/Inflation_Factor/blob/master/221103_%EC%9D%B8%ED%94%8C%EB%A0%88%EC%9D%B4%EC%85%98_%ED%8C%A9%ED%84%B0.pdf) — PDF 3, 29, 30쪽 — 요약 표 2, 본문 표 12~13 및 정상 국면 비교.

## 연구 구성

```text
사업보고서 텍스트·보고서 목록
  → 한국어 형태소 분석
  → Doc2Vec 문서 표현·유사도
  → 종목·업종 노출 점수 및 추가 팩터 처리
  → 포트폴리오 구성·백테스트

CPI·GDP·검색추세 등 거시변수
  → 별도의 인플레이션 예측 실험
```

| 파일 | 역할 |
|---|---|
| `get_inflation_text.ipynb` | 인플레이션 관련 텍스트 처리 연구 노트북 |
| `step2_Doc2Vec.py` | 보고서 문서 임베딩·유사도 계산 |
| `step2_2_Doc2Vec_eachdate.py` | 날짜별 문서 임베딩 실험 |
| `step3_get_Exposure_Score.py` | 노출 점수 계산 |
| `step3_get_Ind_Exposure_Score.py` | 업종 관련 점수 집계 |
| `step3_add_beta.py` | 베타 관련 추가 처리 |
| `step3_convert_Clarifi_style_score_format.py` | 점수 파일 형식 변환 |
| `step3_inflation_model.py` | 거시자료 기반 인플레이션 예측 실험 |
| `step4_backtest.py` | 팩터 포트폴리오 백테스트 |
| `step4_backtest_inflation_model.py` | 인플레이션 예측 실험의 평가 |
| `cls_weight_maker.py` | 포트폴리오 비중 구성 |

## 현재 상태

과거 연구 스크립트를 보존한 저장소입니다. 단일 통합 CLI가 없고, 스크립트별 입력 파일·출력 경로가 다릅니다. 예를 들어 `step2_Doc2Vec.py`는 `simil/`에 저장하지만 날짜별 버전은 `factors/simil/`을 사용합니다. 단계 번호만 보고 모든 파일을 순서대로 실행할 수 있는 구조는 아닙니다.

과거 공시 수집 스크립트가 삭제된 이력이 있으므로, 현재 저장소만으로 원문 수집부터 완전 재현할 수 있다고 가정해서는 안 됩니다.

## 환경 준비

```bash
python -m venv .venv
# 가상환경 활성화 후
python -m pip install -r requirements.txt
```

`requirements.txt`에는 pandas 1.5 계열, NumPy 1.23 계열, gensim 4.2 계열 등 과거 연구 환경의 버전 범위가 기록돼 있습니다. 최신 Python에서의 설치·동작은 별도로 검증해야 합니다. 한국어 분석에는 MeCab·사전 설정이 필요합니다. `cls_weight_maker.py`가 import하는 `riskfolio` 등 requirements에 없는 의존성도 사용 경로에 맞게 정리해야 합니다.

## 입력 데이터

| 경로·파일 | 사용 내용 |
|---|---|
| `data/report_list/` | 공시·보고서 목록 CSV |
| `data/text_inflation/` 등 텍스트 경로 | 문서 처리 입력. 실제 읽는 경로는 스크립트별 확인 |
| `data/backtest_data/` | 가격·배당·시가총액·벤치마크·무위험금리 등 |
| `data/K200const.csv` | 백테스트 구성종목 입력 |
| `data/inflation_model_data/` | CPI·잠재/실질 GDP·검색추세 등 거시자료 |
| `factors/`, `simil/` | 단계별 점수·유사도 입력 및 출력 |

가격·배당·구성종목의 시간축과 종목 코드를 맞춰야 합니다. CSV 열 위치에 의존하는 코드가 있으므로 파일명만 맞추는 것으로 입력이 준비되지는 않습니다. 원천 데이터의 발표 시점·수정 여부도 함께 관리해야 합니다.

## 실행 예시

각 스크립트 상단의 파일 경로·기간·열 선택을 점검하고 해당 입력을 준비한 후 실행합니다.

```bash
# 보고서 목록·원문·출력 디렉터리 준비 후
python step2_Doc2Vec.py

# 해당 점수 파일과 백테스트 데이터를 준비한 후
python step3_get_Exposure_Score.py
python step4_backtest.py
```

위 명령은 각 연구 단계의 실행 형태입니다. 두 번째 명령이 첫 번째 출력만으로 즉시 동작한다는 뜻은 아닙니다. 날짜별 Doc2Vec 버전을 쓰는 경우 입력 보고서 목록과 저장 경로를 함께 변경해야 합니다.

거시 인플레이션 예측 실험은 별도 입력을 준비합니다.

```bash
python step3_inflation_model.py
```

예측 생성·평가 스크립트 간 `CPI_us_prediction.csv`와 `CPI_prediction.csv` 등의 파일명 차이가 있어, 평가 전에 연결 경로를 통일해야 합니다.

## 결과와 연구상 주의점

문서 모델·유사도 CSV·노출 점수·백테스트 결과·거시 예측 CSV 등을 생성합니다. 구체적인 파일명은 선택한 스크립트와 날짜에 따라 달라집니다.

문서 유사도는 경제적 인플레이션 민감도와 동일한 값이 아닙니다. 실제 민감도·수익률과의 관계는 별도 검증 대상입니다. 보고서 공시일과 학습 시점, 문서 길이, 형태소 분석, Doc2Vec의 난수, 데이터 수정 및 미래정보 사용 여부가 결과에 영향을 줍니다. 실무 적용 전 시간순 외부 검증과 비용·업종 노출 분석이 필요합니다.
